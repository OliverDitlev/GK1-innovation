# Jobify

Uddannelsesspecifik jobplatform der matcher studerende med studierelevante 
jobopslag baseret på uddannelse og studielinje, og lader virksomheder målrette 
opslag mod relevante kandidater i stedet for at modtage irrelevante ansøgninger.

## Kør projektet

​bash
npm install
 npx expo start
